# Demo guide

1. Start the API and frontend using the root README.
2. Register a local account, or seed fictional activity with `DEMO_EMAIL`/`DEMO_PASSWORD` and `python ..\scripts\seed_demo_data.py` from `backend`.
3. Explore the dashboard, categories, cash flow, and largest/period spending questions.
4. Upload `data\synthetic\bank_statement_sample.pdf` or `transactions.csv`; inspect/edit the rows, then explicitly confirm.
5. Explore budgets, goals, recurring candidates, insights, local education notes, export and deletion controls.

All sample data is synthetic. Assistant mode is labeled as deterministic/local and is not a paid or generative LLM. There is no live bank connection.
