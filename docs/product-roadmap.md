# Product roadmap

1. Add bank-specific PDF adapters, broader fixtures, balance reconciliation, and optional OCR behind explicit system requirements.
2. Add a formal provider connector only after an authorized consent-based data provider and compliance review are available.
3. Add pgvector-backed document chunks and embeddings, document version refresh, and stronger retrieval/faithfulness evaluation.
4. Add optional LLM provider adapters with secret handling, bounded retries, citation constraints, and cost accounting.
5. Add more frontend integration/accessibility/responsive tests and a real browser end-to-end suite.
6. Add anomaly dismiss/feedback, recurring merchant normalization, forecast uncertainty, and budget/goal contribution analysis.
7. Replace process-local rate limiting, add scheduled preview cleanup, production observability, backups and recovery exercises.
